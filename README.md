# opencode-tools

Личные инструменты для OpenCode. Пока один: честный учёт работы агента —
сколько было заходов, сколько шагов и сколько времени агент реально работал.

Данные берутся из локальной базы OpenCode (`~/.local/share/opencode/opencode.db`),
ничего не отправляется наружу.

## Установка

Нужен Python 3.9+.

```sh
./install.sh
```

Скрипт прогоняет тесты и делает ссылку `~/.local/bin/opencode-tools`.
Заодно подключает TUI-плагин в `~/.config/opencode/cli.json`: после
`/reload` (или перезапуска TUI) в футере появляется строка `Работа: …`.
Удалить всё: `./install.sh --uninstall`.

## Постоянная строка в TUI

В футере промпта:

```text
Работа: 1ч 12м · ход: 3м
```

`Работа` — суммарное время агента по текущей сессии и её субагентам,
`ход` — текущий ход, пока агент работает. Строка обновляется раз в секунду.
Плагин лежит в `plugin/`, в `cli.json` добавляется путь к этой папке.

Если строки нет — выполните `/reload` или перезапустите OpenCode.


## Что показывает

```text
$ opencode-tools stats --days 7

OpenCode · 11–17 ноября 2026

  заходов               5
  промптов             21
  шагов агента        308
  время работы     31м 27с
  инструментов        429
    правок файлов      56
  стоимость        $0.3131

день         заходы  промпты   шаги    время   инстр.        $
──────────────────────────────────────────────────────────────
12.11             1        2     29       3м       59    0.037
13.11             1       11     86       8м      103    0.105
17.11             3        8    193      19м      267    0.172
──────────────────────────────────────────────────────────────
итого             5       21    308      31м      429    0.313
```

* **заход** — сессия OpenCode (корневая; субагенты считаются отдельной строкой);
* **промпт** — сообщение пользователя;
* **шаг** — один ответ агента (assistant step, включая вызовы инструментов);
* **время работы** — сумма длительностей шагов, без пауз между ходами;
* **инструменты** — вызовы инструментов, **правки файлов** — `edit`/`write`/`patch`;
* **стоимость** — из сообщений агента.

## Команды

```sh
opencode-tools time                    # работа последней сессии
opencode-tools time --session ses_...  # конкретная сессия (можно начало id)
opencode-tools time --json

opencode-tools stats                   # сегодня
opencode-tools stats --days 7          # последние 7 дней
opencode-tools stats --days 30 --sessions
opencode-tools stats --all             # всё время, по месяцам
opencode-tools stats --project .       # только текущий проект
opencode-tools stats --json

opencode-tools watch                   # живая строка, обновляется раз в секунду
```

`watch` удобно держать в отдельной панели терминала:

```text
Работа: 1ч 12м · ход: 3м 40с
```

В TUI OpenCode любую команду можно выполнить через `!`:

```text
!opencode-tools stats --days 7
```

## Как считается время

Единица работы — шаг агента: `time.created → time.completed` в
`session_message`. Шаги внутри хода идут подряд, поэтому объединение их
интервалов и есть время, когда агент был занят.

* паузы между ходами (пока пользователь читает или думает) не входят;
* параллельные субагенты объединяются, а не суммируются дважды;
* незавершённый шаг моложе 15 минут считается текущим и растёт до «сейчас»;
* шаги длиннее 30 минут отбрасываются как артефакт миграции;
* для сессий, перенесённых из старого хранилища V1, время берётся из таблицы
  `message`: в V2 у них `completed` записан моментом миграции;
* интервалы, переходящие через полночь, делятся между сутками.

Это время работы агента, а не время CPU и не время, проведённое за компьютером.
Стоимость и токены — из тех же сообщений, поэтому могут немного расходиться с
`opencode stats` (там сессионные счётчики).

## Ограничения

* Работает с OpenCode V2 (`session_v2` / `session_message`). Для V1-базы
  скажет, каких таблиц не хватает.
* Показывает только локальные сессии этого компьютера.
* Часовой пояс — локальный.
